📡 Sobre esta API

Open-Meteo es una API meteorológica de código abierto sin necesidad de API key. Utiliza modelos numéricos de pronóstico del tiempo de alta resolución como ECMWF e ICON. Los parámetros consultados incluyen temperatura, humedad relativa, velocidad del viento, precipitación y código de condición meteorológica (WMO).

Presiona Consultar para cargar datos del portal.
📖 Sobre SODA y datos.gov.co

El portal datos.gov.co usa la plataforma Socrata, la cual expone todos sus datasets vía la SODA (Socrata Open Data API). Se pueden realizar filtros con SoQL (Socrata Query Language), un lenguaje similar a SQL. El identificador del catálogo nacional es 4t9r-7v7i. Los parámetros soportados incluyen $select, $where, $order, $limit, $offset, y $q (búsqueda full-text).
